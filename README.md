## Development environment Settings

0. Set this parameter for the first time after cloning a project：

   ```bash
   npm run setup

   ```

1. Install the VS Code recommended plugin

- Open VS Code
- Go to the extension panel (Ctrl+Shift+X/Cmd+Shift+X)
- Search @recommended
- Install all workspace recommended extensions

2. Make sure the VS Code formatting Settings are turned on

- Open Settings (Ctrl+,)
- Search for "format on save"
- Make sure "Editor: Format On Save" is enabled
